◆ canPoll()

void canPoll ( )

Drains frames waiting in the MCP2515 and applies them to the live data.

Reads up to 32 frames per call straight from the chip (no INT pin needed). Corrupt frames (length > 8, remote requests) are counted and skipped. Valid standard-ID frames are logged (CAN_DEBUG), passed to the frame hook, and decoded with applySignal() for every matching SIGS entry. Does nothing when canOk is false.

Returns
None. Updates frameCount and the shared dash variables.
for (;;) {
canPoll();
delayMicroseconds(100);
}

◆ canSetup()

void canSetup ( )

Brings up the CAN interface: SPI, chip reset, bitrate selection and MCP2515 init.

Sets up the FSPI bus, resets the chip, loads the last verified bitrate/crystal from flash (namespace "kartcan"), and (when CAN_AUTOBAUD is 1) verifies it, scanning 1M/500k/250k/125k with 8 and 16 MHz crystals if it fails. A newly found setting is saved. Finally starts the chip in normal or listen-only mode (CAN_LISTEN_ONLY). Sets canOk to true on success. If CAN_CLEAR_SAVED is 1, the saved setting is erased once per boot first.

Takes up to ~12 s with autobaud, so it runs inside canTask(), not setup().

Returns
None. Check canOk for the result.
canSetup();

void canTask ( void * )

FreeRTOS task body that owns the CAN bus (runs on core 0, never returns).

Calls canSetup(), then loops calling canPoll(). If init failed it retries every 2 s. With CAN_AUTOBAUD it re-runs canSetup() when no valid frame has arrived for 10 s. Yields for one tick every 250 ms so the watchdog stays fed.

bool canTry ( uint8_t rate,
uint8_t clk,
uint32_t ms )

Listens on the bus with one bitrate/crystal setting and reports whether real traffic appears.

Re-initialises the MCP2515 with the given settings in listen-only mode (so it never ACKs or disturbs the bus), then counts frames for up to ms. Success needs 3 plausible frames (standard ID in SIGS, legal length). Prints a summary with CANINTF/EFLG so a silent bus can be told apart from a wrong bitrate. The chip is left in listen-only mode; call CAN0.begin() afterwards to use it.

Parameters
rateBitrate constant from mcp_can, e.g. CAN_500KBPS.
clkMCP2515 crystal constant, MCP_8MHZ or MCP_16MHZ.
msMaximum listening time in milliseconds.
Returns
true if 3 plausible frames arrived in time, false otherwise (including when begin() fails).

◆ decodeSignal()

bool decodeSignal ( const CanSig & s,
const byte * buf,
float & out )

Decodes one signal from a CAN payload into dash units.

Fields of 8 bits or more are read whole-byte, big-endian. Smaller fields (flags, nibbles) are read LSB-first inside their byte. Signed fields are sign-extended, then value = raw * scale + offset. A 8/16-bit field whose raw value is all-ones (unsigned) or signed-max (signed) is treated as "channel not configured in the tune" and rejected.

Parameters
[in]sSignal definition (an entry of SIGS).
[in]bufFrame payload; must hold at least (s.bit + s.len + 7) / 8 bytes.
[out]outDecoded value. Only written when the function returns true.
Returns
true if a valid value was decoded, false if the channel is unconfigured.
const byte frame[8] = {0x1F, 0x40, 0, 0, 0, 0, 0, 0}; // 0x1F40 = 8000
float v;
if (decodeSignal(SIGS[0], frame, v)) { // SIGS[0] = engine speed
