◆ updateAlerts()

void updateAlerts ( )
static

Decides which warning icons to show and flashes them.

A sensor alerts when its value leaves goodLo..goodHi (with a 3% hysteresis before it clears); critical is more than 25% of the range beyond the limit. Launch control shows a steady white icon when armed and a fast green flash when active. Sensors with no data yet never alert. At most MAX_ALERTS icons are shown, highest priority first. The strip is redrawn only when the set changes; otherwise only icons whose flash phase changed are repainted.

Returns
None.
