2/*
3 * can.h - CAN bus (MCP2515) constants, signal table and function declarations.
4 *
5 * SPI: the display uses SPI3 (HSPI); the CAN board uses SPI2 (FSPI). They must
6 * never share a peripheral, or every CAN read is also clocked into the display.
7 * Cores: CAN runs in its own task on core 0; the display loop runs on core 1.
8 *
9 * Signal map: MoTeC M1 "General" CAN protocol, standard 11-bit IDs 0x640-0x65F.
10 * value = raw * scale + offset, already converted to the dash's units
11 * (temps degF, pressures psi, speed mph).
12 */
