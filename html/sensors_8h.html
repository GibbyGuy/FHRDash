◆ sensorsInit()

void sensorsInit ( )

Prepares the gauge cluster: loads saved widget layout and draws the static tach and speedometer.

Opens the "kartdash" preferences, loads the six widget assignments (falling back to defaults if invalid), sets every sensor to its minimum value, marks sensors as seen only in SIMULATE mode, and draws the tach and speed bar. Call after displayInit().

None.

◆ slotHandleTap()

bool slotHandleTap ( int16_t x,
int16_t y )

Handles a tap: if it lands on a side widget, switches that widget to the next unused sensor.

The new choice is saved to flash and the widget is fully redrawn on the next frame. Sensors already shown in another widget are skipped.

Parameters
xTap X in screen pixels.
yTap Y in screen pixels.
Returns
true if the tap hit a widget, false if it hit empty space.
if (slotHandleTap(x, y)) Serial.println("widget cycled");
