Initialises I2C, the TCA9554 expander, the ST7796 panel and the backlight.

Pulses the LCD and touch reset lines through the expander, starts the display at 40 MHz, clears the screen, turns the backlight on, then calls showResetReason(). Prints an error message if the expander or panel fails.

Polls touch every 15 ms and forwards each new tap to slotHandleTap().

Edge-triggered: one press produces one tap. The finger counts as lifted after 3 consecutive polls with no touch. Call from loop() as often as possible.

Reads the FT6336 touch controller and maps the point to screen coordinates.

Applies the TOUCH_SWAP_XY / TOUCH_FLIP_X / TOUCH_FLIP_Y settings so the result matches the 480x320 landscape layout.

Parameters
[out]sxScreen X (0..479). Only valid when true is returned.
[out]syScreen Y (0..319). Only valid when true is returned.
Returns

Shown for brownout, panic, and the interrupt/task/other watchdogs. Normal resets (power-on, software, reset pin) show nothing. Blocks while displayed, then clears the screen.

Draws centred text only if it changed, clearing leftovers of the old text.

Returns immediately when the string and colour match what is already on screen. Otherwise the new text is drawn opaque and any part of the old text's bounding box not covered by the new text is erased. Uses the 6x8 built-in font scaled by size.
