Prints a received CAN frame (ID and raw bytes), rate-limited per ID.

Only active when CAN_DEBUG is 1. Each distinct ID prints at most once every 250 ms, and up to 48 distinct IDs are tracked, so the serial port cannot flood.

Parameters

exttrue for a 29-bit extended ID, false for standard 11-bit.
