void wirelessBegin ( )

Starts the Wi-Fi access point, web server and WebSocket stream of raw CAN frames.

Creates the frame queue, registers the CAN frame hook, and launches the "wifi" task on core 0. The task waits 1.5 s, starts the AP (SSID/password from this file, max 2 clients), serves the dashboard page at http://192.168.4.1/ and streams frames on WebSocket port WS_PORT. Does nothing when ENABLE_WIRELESS is 0.

Returns
None.
